# AI Voice Cloning Platform

Welcome to the ultimate local AI Voice Cloning platform! This is a complete, offline Artificial Intelligence system that lets you clone any voice and generate hyper-realistic speech. 

It features a custom **Latent Chunking Engine** and a **Studio Mastering Pipeline** to ensure voices sound incredibly emotional, crisp, and 100% human, without any robotic background noises.

---

## 🚀 How to Install

We have built automated installers so you don't need to be a programmer to set this up.

### If you are on Windows:
1. Download this entire folder to your computer.
2. Double-click the file named `install_windows.bat`.
3. A black window will open. Just sit back and watch! It will automatically download everything your PC needs (like Python, Node.js, and the AI models). 
4. This might take 5-10 minutes depending on your internet speed. Wait until it says "INSTALLATION COMPLETE".

### If you are on Mac (Apple Silicon Recommended):
1. Download this entire folder to your computer.
2. Open your `Terminal` app.
3. Type `sh ` (with a space at the end), drag the `install_mac.command` file into the terminal, and hit Enter.
4. It might ask for your Mac password to install Homebrew and Python. Type it in (it won't show the letters while you type) and hit Enter.
5. Wait for it to say "INSTALLATION COMPLETE".

---

## 🎧 How to Use

1. **Start the Engine:**
   - **Windows:** Double-click `start_all.bat`.
   - **Mac:** Open terminal and run `sh start_all.sh`.
2. **Open the Website:**
   - Open your web browser (Chrome, Safari, etc.) and go to: `http://localhost:5173`
3. **Clone a Voice:**
   - Go to the **Voice Cloning** page.
   - Upload a 10-second clear audio clip of the person you want to clone.
   - Type the text you want the voice to say and click "Initialize Clone Sequence".
   - The AI will process it and give you a perfectly mastered, studio-quality clone!

*(Note: Keep the black terminal windows open while you are using the app. When you are done playing with it, just close those black windows to turn the AI off).*
